Meal planner disclaimer

The dialog below is the one index.html shows the first time someone opens the Metabolic Meal Planner. Markup, CSS and behaviour are copied verbatim.

To check the accessibility: click Reopen, then use Tab and Shift+Tab — focus cycles inside the dialog and cannot reach this page behind it. Esc declines. Focus lands on the heading first, so a screen reader reads the title and the text before the buttons. On close, focus returns to the button you opened it from.
